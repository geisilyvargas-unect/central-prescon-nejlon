PASSO 02

Instalar seu Apps Script privado

Você só precisa fazer a configuração inicial uma vez. Depois, o próprio Google executa a sincronização em intervalos de aproximadamente seis horas, dentro dos limites do serviço.

  1. Acesse Criar novo projeto no Google Apps Script. Use sua conta da PRESCON e não compartilhe o projeto com os editores da planilha.
  2. Copie o arquivo Código.gs para o editor do projeto. O arquivo appsscript.json contém o manifesto de permissões.
  3. Em Configurações do projeto → Propriedades do script, adicione os dois valores abaixo. A chave é aquela que você copiou no Passo 01.
  4. No editor, execute instalarCentralPrescon e conceda as permissões solicitadas pelo Google. Não é necessário publicar como aplicativo web.
  5. Confira na planilha a nova aba PRESCON_AUTOMACOES. Somente essa aba será gerenciada pelo script; as outras continuarão intactas.
